# lqr_v2：轮腿 10 维 LQR（独立重新推导）

本目录不引用 `lqr_sim/` 的任何结论。参数取自参数表截图和 `标定结果.docx`，符号约定逐条对照了固件 `balance.c / LQR.c / VMC.c / chassis.c`。

## 产物

| 文件 | 内容 |
|---|---|
| `out/K_full_l030.c` | 完整 4×10 K，腿长 0.30 m，1 kHz，可以直接粘贴 |
| `out/K_bench_l030.c` | 板凳模式 K（只用轮子两行）和推荐的锁腿位置指令 |
| `out/A_code_l030.txt`, `out/B_code_l030.txt` | 固件坐标下的 A、B 矩阵 |

要换腿长，运行 `python run_all.py 0.35` 即可。依赖只有 numpy 和 sympy，不需要 scipy。

## 符号约定（K 就是按这套约定算的，粘贴后不要再翻转任何列）

| 量 | 正方向 | 固件来源 |
|---|---|---|
| s, ds | 车前进 | 两轮编码器平均值，左轮取负 |
| yaw, dyaw | 左转 | `IMU.Yaw`, `Gyro[2]` |
| θ, dθ | 轮心在髋前方（以世界竖直为基准） | 五连杆摆角 − Pitch |
| φ, dφ | 车头上抬 | −Pitch, −Gyro[0] |
| T_w | 驱动轮子前滚 | 右轮 ×3318.833，左轮 ×(−3318.833) |
| T_p | 使 θ−φ 增大（轮子相对机体往前摆） | Tf = Tb = Tp/2，左腿取负 |

控制律为 `T = −K(x − x_ref)`，也就是 `LQR_calc` 现在的写法，`rate = 1.0`。

## 模型要点（与上交文档或常见写法的区别）

1. **轮毂编码器测的是轮相对小腿的转角。** 因此固件算出的 s 等于"轮心对地位移 + R·θ"，并不是真实轮心位移。模型先在物理坐标下推导，再精确变换到固件坐标，所以 K 能直接作用于固件的 s。
2. **计入了转子反射惯量 J·N²。** 估算值约 3.0e-3，比 I_w + m_w R² = 2.5e-3 还大。转子角速度为 θ̇ + N(−ẋ/R − θ̇)，轮力矩的反作用力矩作用在小腿上。
3. **机体平动坐标取在机体质心，不取在髋点。** 上交 3.6 式取的是髋点，3.14 式还有 `θ̈_l,r` 应为 `θ̈_b` 的笔误。
4. **偏航角由两髋连线定义。** 这与 IMU 测到的机体 yaw 一致，腿摆动对偏航的耦合会自动进入 A 矩阵。
5. **用两种方法独立推导。** 一是拉格朗日法（`model_lagrange.py`，sympy 符号推导），二是牛顿-欧拉法（`model_newton.py`，逐个刚体列受力方程，包括减速箱内力）。在 l = 0.2/0.3/0.4、J_r 取 0 和 1.2e-5 的各种组合下，两者的 A、B 相对误差都约为 1e-15。

## 参数（l = 0.30 m）

| 参数 | 值 | 来源 |
|---|---|---|
| l_b（腿质心到髋）/ l_w（腿质心到轮心） | 0.0733 / 0.2267 | 用 l=0.40 的表值拟合五连杆质量分布后重新计算 |
| I_l | 0.0327 | 表值按五连杆模型随腿长的变化比例缩放（腿缩短时膝外张，惯量变大） |
| J_rotor | 1.2e-5 | 估算值。验证中扫过 0 到 3e-5 |
| I_bz（机体偏航惯量） | 0.10 | 估算值。验证中扫过 ×0.5 到 ×2 |
| 其余 | 按参数表；R_l = 0.24 | |

权重按 Bryson 规则取（σ 为可接受的最大偏差）：s 0.4，ds 0.8，yaw 0.5，dyaw 2，θ 0.3，dθ 3，φ 0.12，dφ 1.5；T_w 1.5，T_p 6。设计在离散域进行（ZOH，Ts = 1 ms，DARE）。

## 验证结果

- **闭环极点。** 最慢的一对为 −1.57 ± 0.87j，最快的为 −127 rad/s。在额外延迟达到 10 ms 之前，离散闭环都保持稳定。
- **参数失配。** 用标称 K 去控制失配的对象，以下工况全部稳定，延迟裕度为 9 到 17 ms：J_r 取 0 或 3e-5，l_c 取 −0.03 到 +0.05，I_bz 取 ×0.5 或 ×2，I_l 取 ×0.6 或 ×1.5，l_b 偏 ±3 cm，机体加 2 kg，R_l 取 0.19，实际腿长为 0.25 或 0.35。
- **非线性仿真。** 用完整的拉格朗日方程仿真（RK4，1 拍延迟，带限幅），φ 偏 15°、θ 偏 15°、受到 1.5 m/s 冲击、yaw 偏 1 rad 四种情况全部收敛。最大的峰值轮力矩出现在 1.5 m/s 冲击时，为 4.36 N·m（上限 4.94）。
- **板凳 K。** 闭环最慢极点为 −1.16，延迟裕度 37 ms。

## 板凳模式说明

锁腿后，θ 的平衡点约为 0，与锁定角度无关；φ 的平衡点则等于 −θ_rel0。以现在锁定的位姿为例（右腿 θ_rel 约 +3.8°，左腿约 −2.0°），如果角度增益放在 φ 列且目标为 0，就会产生一个固定偏置，车会朝一个方向跑。因此板凳 K 把角度增益平分到了 θl/θr 两列，φ 列为 0。对现有锁定位姿（l = 0.353）重新设计，得到的 K 与 0.30 的结果相差不到 2%。

## 上车极性检查（按手册阶段 B/C）

| 操作 | 应看到的结果 |
|---|---|
| 板凳模式，手把车头往下压（φ<0，θ<0） | T_w > 0，轮子向前加速 |
| 板凳模式，把车往前推一段（s>0） | 先出现短暂的 T_w > 0（把车体压回去），随后轮子往回拉。这是倒立摆的非最小相位特性，不是极性错了 |
| 完整模式，单独把一条腿的轮子往前拨（θ>0） | 该腿 T_p < 0（约 −10.7 N·m/rad），同时 T_w < 0，两者一起把轮子收回髋下方 |
| 完整模式，车头上抬（φ>0） | 两腿 T_p > 0（约 +32 N·m/rad），反作用力矩把车头压下去 |

## 已知风险（与 K 无关，但切换到力矩模式前必须处理）

1. **左前电机读数跨了一圈。** 标定时读数为 +3.25，现在锁定指令为 −2.777，两者差约 2π。这会让 β 差 2π，使 `VMC_Calc` 里的 `sin(β/2)` 变号，腿长力随之反向。五连杆正解只用到 sin/cos(α+β)，不受影响。修复方法有两种：把 β 归一化到 (−π, π]，或者重新设置该电机零点，使工作区间不跨 ±π。
   左腿重新标定的方法：先把两台左腿电机的零点设在"轮心在髋正下方、腿最长"的位姿，然后用 `calib_left.py` 根据新读数算出要改的代码行，脚本会同时给出自检结果。
   如果以后要做倒地自起这类需要电机转整圈的功能，从根上修要靠软件：在 `*_Alpha_beta_calculate` 末尾把 β 归一化到 (−π, π]；每个关节读数按 2·P_MAX 做多圈展开；位置模式的目标改成"当前读数 + 角度差"。这三处改好以后，零点设在哪里都不影响正确性，重新设零只是让读数更好看。
2. **VMC 腿长力方向反了（已确认）。** 按虚功原理逐点核对，在 l = 0.405、0.30、0.20 三个位置，`VMC_Calc` 输入 F = +1 时腿都会缩短。而 `PIDCalculate` 的误差是 Err = Ref − Measure，腿偏短时 F > 0，结果会让腿缩得更短，形成正反馈。修复方法是把 Tf、Tb 里 g 项的符号整体取反，并加上重力前馈 F_ff = (m_b/2 + m_l/2)·g ≈ 29 N。现在的 Kp = 90 N/m 远远托不住车体，建议起步取 Kp 约 800、Kd 约 40、MaxOut 约 150 N，再上车调整。
3. **左腿两段注释的符号不一致。** `l_VMC_Calc` 里已经取过一次负，所以下发时应使用 `SetRef(l_Tf)`，不能再写 `SetRef(-l_Tf)`。
