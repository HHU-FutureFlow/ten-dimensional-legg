# Wheelleg 摩擦测定与复测手册

适用于四台 DM8009 关节和两台 C620 驱动轮。机械重装、更换电机或减速器后，可按以下流程重测。台架固件负责单电机力矩、摆位和采样，离线工具负责按所选窗口复算。2026-11-22 的各笔结果和历史固件版本见 [摩擦测定记录](摩擦测定记录.md)。

## 1. 台架和零力基线

1. 架稳车身、两轮离地，确认联动小腿和轮胎都有活动净空。记录装配状态、外载、朝向和初始姿态。在有支撑的情况下开始或复位台架。撤力后腿仍可能受重力回摆，轮仍有滑行。
2. 执行 `.scriptsproject.ps1 -Action build -BenchDebug`。烧录 `build/bench-debug/basic_framework.hex`，在 EmberProbe 选择同次构建的 `basic_framework.elf`。核对板上固件指纹，重新解析当前 ELF 的请求变量地址和类型，记录 SHA-256。操作权限按 [AGENTS.md](../AGENTS.md#固件与硬件操作)。
3. 先只读 `friction_dbg`。确认 tick 递增、有效反馈不断更新、`state=2`、无保持、各路力矩指令为零。DM 力矩帧核对 `Kp=Kd=0`，驱动反馈首字节高四位（ERR）为 1 表示使能，0 表示失能。若红灯且反馈仍更新，读驱动状态；本次通过台架主控复位重发 DM 初始化使能帧，再确认使能且零力。首个小力矩档须看到反馈力矩随指令改变，方可用于起动判断。
4. 若存在此前试验的故障锁存，先读 `gate_reason` 与 `reset_ready`，确认当前工况、反馈和执行器已停稳后，用新序号发送 `0xE000`，读回已复位和零力。通用原始力矩在当前版会持续输出，开测前备妥新序号的 `0xD004` 撤力及现场断动力手段。失去通信时依靠现场断动力。
5. 写请求前核对当前序号、预期字、符号及所选电机。写后核对 EmberProbe 读回、`request_id`、`request_result`、`state` 和实际力矩反馈。每笔结束核对 `last.id` 和指令为零或大腿仍保持的预期状态。读不完整时，先按原序号补读，避免重发动作。请求编码、状态枚举和采样字段见 [台架接口](../application/debug_mode/README.md)。

重装后把左右腿摆到相同参考位，用原始编码器和虚拟腿观测核对 α（大腿对车身向下的角）、β（张角）、虚拟摆角和腿长。机械对称位实读可用于重新核对左右角零点。当前右侧偏置来自本次对称位标定。 [运动学](../application/chassis/balance.c)

## 2. 大腿原始力矩测定

1. 选一台大腿电机，另一侧零力，同侧小腿零力自由随动。V3 通用原始力矩请求保持 bit12 清零。记两关节原始编码器、α、β、摆角、腿长和负载。关节的正负按各自电机原始方向。
2. 从停稳的同一姿态开始，正反向分别逐档增加短脉冲，记录出力前、出力期和撤力后的命令、角度、速度、反馈力矩。历史大腿使用 600 ms 观测窗，当前版通用入口靠 `0xD004` 主动撤力，按实读板端 tick 记录实际时长。同步记录同侧小腿随动。小量跳动、短滑和持续滑动分别标记。
3. 本轮关节粗扫以 0.5 N·m 为步长，左侧 8 N·m、右侧 5 N·m 是当轮授权上限。重装后按当次台架工况设定扫档。接近首次持续滑动时缩小档差，并保留最大未持续起动与最小持续起动之间的区间。停稳后把腿摆回原参考点，再取反向和重复样本。若姿态漂移，按姿态分组记录。
4. 取相近 α、β、速度幅值和小腿随动比的正反向近匀速窗。自由随动下得到的是该装配与工况的等效动摩擦。缺少匹配窗口时保留起动边界、有效运动段或单方向观测。

## 3. 小腿原始力矩测定

1. 将大腿摆到车身后方接近水平，让小腿接近竖直且正反方向都有净空。可手动托好并用 `0xD005` 捕获实时大腿角，或用 `0xD006` / `0xD007` 自动摆位（分别关闭 / 开启摆位时的大腿运动摩擦前馈）。捕获以大腿稳定为准。确认 `state=10`、双侧大腿目标和反馈稳定、两侧小腿力矩为零，记录实际姿态。
2. 用专用双侧小腿脉冲请求 `0xF000` 选择被测侧，低 11 位按 8 mN·m/码编码。每笔 600 ms，每 5 ms 板载采样，通常共 121 点。结束后小腿回零，大腿继续保持。改变起点时先等被测侧停稳，并记录或恢复参考姿态。
3. 用 `friction_calf_trace.id`、`count`、逐样本时间戳核验本笔轨迹。在下一笔覆盖缓冲前保存数据。分析窗内同时观察大腿电机角和小腿角。大腿被带动、触限位、反馈失效或明显加减速的片段需在记录中标明。小腿复测沿用同样的保持方式与初始姿态。完成全部试验后用 `0xD004` 撤掉大腿保持并核对零力。

## 4. 车轮架空测定

1. 让待测轮离地自由转动，确认腿部有台架支撑。车轮测定无需执行腿部摆位。记轮端起始角，正负统一为车辆前进坐标。
2. **右轮**用 V3 `0xB000` 专用脉冲，1 mN·m/码，出力 600 ms 后零指令滑行 400 ms。每 5 ms 板载采样，通常 201 点。右轮历史由 0.020 N·m 小步长粗扫，临界处细化至 0.001–0.002 N·m。
3. **左轮**用 V3 通用原始力矩，执行器编号 2，4 mN·m/码。记录出力与零力滑行轨迹时用 EP 连续采样，并用新序号的 `0xD004` 主动撤力。该入口的持续时间与采样周期以板端 tick 的实读为准。历史左轮试验使用带速度保护的旧版，旧保护设置和结果见测定记录。
4. 分别从相近轮位重复各方向的小步长扫描。记录持续起动阈值区间、轮位变化和短动。停稳后换轮位复查。动摩擦估计取轮速仍保持原符号、撤力瞬态已过的滑行段。右轮本次拟合从撤力后至少 35 ms 开始，并取速度幅值 1–6 rad/s 的窗口。
5. 用减速度乘轮端等效惯量估计阻力。当前名义惯量 `J = Iw + N²Jr = 0.00369068 kg·m²`。若能可靠估算零指令后的残余电流力矩，沿运动方向取其均值并加到惯量估计上，同时保留修正前结果。换减速器或轮子后按实际轮端惯量更新。架空测试结果按对应装配条目记录。 [惯量参数](../lqr_v2/params.py)

## 5. 数据处理和归档

- **起动门槛**记本工况下最大未持续起动与最小持续起动力矩，正反向各留一组。附上峰速、位移、观察时长和实际力矩反馈。短动和疑似顶限位保留原样。
- **关节运动摩擦**用同姿态、同负载、相近速度幅值的正反向近匀速窗。令有符号的反馈力矩中值为 τ₊、τ₋，运动摩擦候选为 `(τ₊ − τ₋)/2`，同时得到恒定负载偏置估计 `(τ₊ + τ₋)/2`。若样本仍有明显加速度或姿态差异，半和会混入力矩偏差；报告窗口差异和置信程度。先驱动后逐步减矩的试法也可以取同工况的近匀速点，单方向的零加速度点给出的是摩擦与同方向负载的合力矩。
- **车轮运动摩擦**拟合滑行速度幅值随时间的斜率 `k`。零指令估计为 `−Jk`，有残余力矩时再按上节修正。记录速度窗、拟合点数、拟合优度、轮位和惯量来源。
- **归档**每笔留固件 SHA-256、请求序号和读回、执行器、符号与命令、试前及撤力后状态、起始 α/β/摆角/腿长或轮位、负载与保持配置、原始轨迹、分析窗口和结论。统一使用板端毫秒、rad、rad/s、N·m。原始角读数跨轮时保留连续编码器值。旧临时目录只是历史数据的位置提示。

### 离线分析工具

`scripts/friction_analyze.py` 使用 Python 3.10+ 标准库。输入是每笔按时间排序的 CSV、JSON 采样数组或包含 `data` 数组的 JSON 对象。字段为 `elapsed_ms,position_rad,speed_rad_s,torque_nm`，小腿可带 `thigh_position_rad`。用 EP 保存板载采样树后，将各元素的 `members` 展平为字段值；版本支持 `--snapshot-csv` 时可直接导出单变量数组表。若分段读取数组，按绝对索引合并后复核 `id`、点数、顺序及时间戳。工具输出所选窗口和测量结果，操作者负责核对工况、起动分类和姿态匹配。 [工具源码](../scripts/friction_analyze.py)

以下命令可在仓库根目录复算本轮两组代表性样本。

```powershell
python scripts/friction_analyze.py joint .Doc/friction-samples/left-calf-16.csv .Doc/friction-samples/left-calf-15.csv --pos-ms 110 150 --neg-ms 310 350
python scripts/friction_analyze.py wheel .Doc/friction-samples/right-wheel-15.csv --direction positive --time-ms 635 1000
```

预期左小腿半差 0.936 N·m、半和 +0.026 N·m。右轮第 15 笔未修正约 0.096 N·m、计入残余力矩约 0.106 N·m。三个 CSV 保留该笔全部板载采样点。其序号、工况、ELF 和台架统计见 [左小腿复测](摩擦测定记录.md#左小腿断电后复测)与[右轮测定](摩擦测定记录.md#2026-11-22-右轮架空测定)。

## 6. 回填普通模式与本轮收尾

按各电机回填动摩擦候选，关节在 VMC 输出后使用原始电机坐标叠加。两轮先在前进坐标合成，左轮下发时再换向。前馈由计划速度决定，实测速度继续用于反馈阻尼。计划速度归零时，摩擦项回零。调试版的摆位候选也在对应系数表中维护。 [普通模式](../application/chassis/chassis.c) · [台架版](../application/debug_mode/friction_test.c)

本轮经历了虚拟腿长与归零探索、DM 零力排查、大腿原始力矩粗细扫、小腿摆位与断电复测，以及左右轮架空起动与滑行估计。直接按实测速度给全量前馈的台架试验出现摆动。后来按五次轨迹的计划速度补偿，实测速度参与反馈，25% 和全量两版均走完收腿和回摆并捕获保持。全量方案随后接入普通模式，用户反馈重调后整车控制明显改善。当前轮端系数仍来自架空工况，整车反馈为定性观察。 [完整实测记录](摩擦测定记录.md)
