# EP 摩擦测定台架固件

此固件适用于当前单板、四个 DM8009 关节和两个 C620 驱动轮。上电六路零力。被测电机的应用层力矩只来自 EP 试验请求。摩擦前馈、重力补偿、LQR 和普通底盘控制都不进入测定路径。电机仍使用原驱动和反馈。

整车复测步骤、数据归档和可复算样本见 [Wheelleg 摩擦测定与复测手册](../../.Doc/摩擦测定手册.md)。

## 构建与加载

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/project.ps1 -Action build -BenchDebug
```

架稳车身并留出腿的活动空间，轮胎离地，确保现场可直接切断电机动力。烧录 `build/bench-debug/basic_framework.hex`。在 EmberProbe 选择同一次构建的 `build/bench-debug/basic_framework.elf`。烧录或重置时车身和腿应有支撑，因为零力后仍会受重力或惯性运动。

## 上电、出力与撤力

上电进入 `state=2` 零力待试。确认 `friction_dbg.tick` 递增、拟测关节的 CAN 反馈首字节高四位为 `ERR=1`。原始力矩请求持续出力，使用带新序号的 V3 `0xD004` 结束。EP 断开时也会持续出力，现场可直接切断动力。

台架应用已取消速度、行程、堵转、角度偏差、动作时限和每路软件输出限幅。速率、最大行程和出力时长仍记录。命令范围由 V2/V3 编码和底层驱动决定，C620 电流码为 ±16384。位置闭环继续检查反馈有效性和后关节帧更新，控制器积分有界。反馈故障回到零力并锁存，反馈恢复后可用 `0xE000` 清除。

## 原始力矩与伴随保持

一笔力矩请求只驱动所选电机。关节请求的 bit12 可开启同侧另一关节的位置保持，目标为试验起点。轮电机请求须清除 bit12。提交 V3 `0xD004` 将试验及伴随保持一并撤力，摘要保存在 `last`。

## 大腿定位与保持

- V2/V3 的 `0xD000` / `0xD001` 分别驱动左/右大腿到 α = 0。达到角度和速度窗口并持续 300 ms 后撤力。
- V3 目标角请求的低 16 位为 `0xC000 | (right ? 0x0800 : 0) | (angle_code & 0x07FF)`，其中 `angle_code = alpha_mrad / 4`，目标取 −π ≤ α < 0。目标 −0.752 rad 对应左 `0xC744`、右 `0xCF44`。到位后进入 `state=9` 保持，同侧小腿零力。
- V3 `0xD005` 同时捕获两台大腿的当前角度，进入 `state=10` 保持，小腿零力。读取 `friction_dbg.thighs_hold` 核对锁定目标和大腿力矩。
- 大腿保持期间可以提交同侧小腿的 V3 原始力矩试验，双侧保持时可以任选一侧，bit12 置零。V3 `0xD004` 撤掉当前试验及保持。

## 双侧定腿长和虚拟摆角归零

V2/V3 的 `0xD002` 启动双侧动作，先以五次轨迹向 0.30 m 收腿，再按五次轨迹向机体系虚拟腿角 0° 回摆。四路电机的参考峰速不超过 0.30 rad/s，各路摩擦前馈以原始电机坐标的计划速度计算，系数取台架候选的 100%。实测速度参与速度误差反馈。

每段参考走完后，若四路实测电机角在 500 ms 内各自的变化范围不超过 0.01 rad，即认为该段停稳。回摆后捕获实际电机角，并延续静态支撑力矩做闭环保持。记录捕获时的实际腿长和虚拟腿角。V3 `0xD004` 或 `0xD003` 主动撤力。

## 小腿测定摆位与采样

V3 低 16 位 `0xD006` / `0xD007` 自动摆位，分别对应关闭 / 开启大腿运动摩擦前馈，台架 `state=11`。参考走完后，两侧实测大腿角相对窗口起点变化都在 0.025 rad 内持续 300 ms，即捕获实际角进入 `state=10`，两侧小腿指令回零。

双侧大腿保持时，小腿测定请求的低 16 位为 `0xF000 | (right ? 0x0800 : 0) | (torque_code & 0x07FF)`，低 11 位补码每码 8 mN·m。每笔持续 600 ms，板端每 5 ms 保留小腿角、速度、反馈力矩和同侧大腿电机角。正常完成后被测小腿回零，双侧大腿继续保持。用 `friction_calf_trace.id` 和 `count` 核对本笔，数组读取 `friction_calf_trace.samples[0:121]`。

## 轮端力矩与滑行

右轮可在零力待试状态直接测定。V3 低 16 位为 `0xB000 | (torque_mnm & 0x0FFF)`，低 12 位为每码 1 mN·m 的有符号补码。每笔先出力 600 ms，再以零指令记录 400 ms 滑行。兼用 `friction_calf_trace` 保存 201 点，读取区间为 `samples[0:201]`。`position_rad`、`speed_rad_s` 为轮端值，`torque_nm` 由 C620 反馈电流换算。

左轮使用通用原始力矩入口（执行器 2）。需要连续采样并用新序号主动撤力，见复测手册。

## EmberProbe 请求与观察

`friction_ep_request_v3` 与 `friction_ep_request_v2` 均为对齐的 32 位 RAM 变量，共用同一序号。高 16 位为序号，bit15–13 选电机，bit12 控制伴随关节保持，低 12 位为有符号补码。V3 每码 4 mN·m，V2 每码 2 mN·m。0.5 N·m 粗扫使用 V3，每档 125 码。

选定相应编码步长的力矩，用 `torque_code = torque_mnm / step_mnm` 计算指令字 `(id << 16) | (actuator << 13) | (hold ? 0x1000 : 0) | (torque_code & 0x0FFF)`。例如 V3 ±8.00 N·m 对应 ±2000 码。上电从序号 1 开始，每次增加，跳过 0。以 `friction_dbg.request_id` 为已消费序号。两路同拍有新请求时选择更新的序号，相同序号优先 V3。启动当拍、故障锁存和忙碌期间收到的力矩请求会被消费并丢弃。

故障复位可用任一请求变量，合成式为 `(id << 16) | 0xE000`。反馈恢复并显示 `reset_ready=1` 后发新序号。成功后 `request_result=6`，回到零力待试。

| 观测字段 | 用途 |
| --- | --- |
| `request_id` / `request_result` | 最后消费的序号。结果为 0 无、1 被安全门拒绝、2 接受、3 非法请求、4 忙、5 反馈无效、6 已复位、7 复位条件未满足、8 单侧预定位或到位保持、9 主动撤力 |
| `state` / `gate_reason` / `reset_ready` | 0 零力阻断、2 零力待试、3 正在测定、4 故障锁存、5 大腿预定位、6 虚拟腿角归零、7 虚拟腿角保持、8 调整腿长、9 单侧大腿保持、10 双侧大腿保持、11 小腿测定摆位，可复位时置 `reset_ready = 1`。原因见 [FrictionEnd_e](friction_test.h) |
| `actuator` / `trial_id` | 0 左大腿、1 左小腿、2 左轮、3 右大腿、4 右小腿、5 右轮、6 未选。试验编号等于该次请求序号 |
| `command_nm` / `position_rad` / `speed_rad_s` | 本拍力矩参考、位置、速度。关节采用电机原始方向，轮端以前进为正 |
| `feedback_valid` / `feedback_torque_nm` / `wheel_current_raw` | 反馈有效标记、DM 力矩反馈或按电流码估算的轮端力矩、C620 电流原始码 |
| `thigh_alpha_rad[0/1]` / `leg_beta_rad[0/1]` | 左右大腿相对车身向下的姿态角、五连杆张角。看 `leg_angle_valid_mask` 的位 0/1 确认有效 |
| `leg_theta_body_rad[0/1]` / `leg_theta_valid_mask` | 五连杆虚拟腿摆角，相对车身向下；位 0/1 对应左/右 |
| `leg_length_m[0/1]` | 左右虚拟腿长（m），有效位与虚拟腿摆角共用 |
| `prep` | 最近预定位序号、执行器、目标/实际大腿角、峰值力矩、时长和退出原因。`holding` 在保持和同侧小腿试验中持续置 1，`command_nm` 独立给出大腿力矩；`peak_joint_speed_rad_s` 记录到位前两关节最大速度 |
| `thighs_hold` | 双侧原位保持标志、两侧目标大腿角和指令力矩 |
| `virtual_zero` | 双侧动作的序号、是否进入保持、捕获的电机角与腿长及摆角、四路计划速度、实际前馈和力矩指令。关节数组按左右、前后排列 |
| `peer_hold_active` / `peer_hold_target_rad` / `peer_hold_command_nm` | 保持状态、位置目标和下发保持力矩，角度使用关节电机原始方向 |
| `last` | 最近结束的试验，含符号力矩、峰值、时长、结束原因、反馈，以及 `peer_hold` 和 `peak_peer_hold_nm` |

用时间戳和序号对齐命令与反馈。起动门槛单独记录。估计动摩擦取同一姿态和相近速度绝对值的正反向有效段，注明承载和装配条件。疑似堵转样本单独留档。轮端绝对力矩精度受电流到力矩换算影响。
